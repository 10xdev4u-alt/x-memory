# Changelog

## v1.0.0

First release. The memory layer for the real-time web.

- Session sync for bookmarks and likes with resume and multi-account isolation.
- Library with search, clusters, saved views, collections, and bulk export.
- Reader with briefs, media, threads, and resolve loops.
- Intelligence: claim tracking, contradiction pairs, prediction ledger, wagers, ask-your-saves.
- Habits: spaced review with streaks, trust ranking with missed posts, voice digests.
- Morning Paper artifact with overnight scheduling and audio playback.
- Sharing: portable links, forks, taste profiles, leaderboards, visibility gates.
- Backend: public objects API with owner takedowns and abuse reports.
- Privacy: local-first, opt-in diagnostics, published policy.
