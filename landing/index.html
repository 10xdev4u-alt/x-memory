x-memory Privacy

Local-first memory for the posts you choose to keep

Keep the useful parts of X close.

x-memory is a browser extension for saving, searching, and reflecting on the X posts you choose. Your corpus stays on your device until you explicitly share an object.

    Local corpus

    Saves stay searchable.

    Browse saved posts, filter them, and keep briefs beside the source text. Search runs against the local corpus.

    User-controlled session

    Use the session you already have.

    When you choose an X flow, the extension uses your active X session. It does not ask for a second account or an API key.

    Reflection tools

    Turn saves into a quieter review.

    Read saved posts, generate a brief, or assemble a Morning Paper from the local corpus.

    Privacy by default

    Your memory stays local by default.

    Corpus data, settings, and backups stay in your browser. X requests occur in the sync, brief, and paper flows the extension exposes. Explicit sharing can send a selected object to a configured API.

    Build from source

    Run the extension locally.

    There is no hosted install claim here. Clone the repository, install dependencies, build the extension, and load the unpacked build in Chrome.

    npm ci
npm run build
npm run smoke:extension
